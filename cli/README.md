# svtui

Terminal-aesthetic Svelte components, delivered as self-contained source files
you copy into your own project (shadcn/ui-style). Minimal deps, monospace-first.

> ⚠️ **0.0.1 is a placeholder release to hold the `svtui` name on npm.**
> The `init` / `add` / `list` commands ship in **0.1.0**.

## Planned usage

```sh
npx svtui init
npx svtui add button
npx svtui list
```

Each command writes a flattened, dependency-free `.svelte` file into your
`src/lib/components` directory — you own the source.
